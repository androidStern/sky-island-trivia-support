Your island is in Messages

To play, return to the Messages conversation where you received this game and tap its Sky Island Trivia game bubble. Use the Sky Island Trivia iMessage extension to take your turn.

If you do not have the game, ask the sender how to install the current version. Update the game on every player's iPhone before starting a new group game.

This website does not open or display the game data in your link. It does not forward that data to another service. Keep the full game link private: anyone you send it to can receive the encoded player names and game history in that bubble.

Updated versions can open earlier game bubbles. Older installed versions cannot understand the new link format; all players should update before a new game.
